# Simple-Frontend-and-Backend-connection
🎉 A simple full-stack demo project showing how to connect a frontend (HTML, CSS, JS) with a Node.js + Express backend using fetch() API.  Click the button to send a request to the backend and see a celebration animation when the connection succeeds!
# Frontend-Backend Connect 🎯

## 📖 Overview
A simple project demonstrating how a frontend communicates with a backend using Fetch API.

## 🧠 Features
- Express.js API endpoint
- Fetch API connection
- Auto confetti animation 🎊
- Simple and beautiful UI

## ⚙️ Tech Stack
HTML, CSS, JavaScript, Node.js, Express, CORS

## 🚀 How to Run
1. cd backend
2. npm install
3. nodemon server.js
4. cd ../frontend
5. npx live-server
